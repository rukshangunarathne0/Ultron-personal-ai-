# RUK-AI // Ultron Personal AI

Personal AI Command OS built for **Rukshan**, featuring:
- **Scary Red & Black Animated HUD Chamber** with a live 7-step cognition & task circuit (`STEP 01 UNDERSTAND` → `STEP 07 REPLY`).
- **Centered Biomechanical Ultron Avatar Rig** with cursor-tracking optics, natural eyelid shutters, angry brow plates, lightning arcs, and 60fps real-time mouth/cheek furnace plasma lip-sync.
- **Persistent RUK-AI Memory Architecture** implementing `<profile>`, `<memories>`, `<recent_chat>`, `<request>`, and `<memory_update>` JSON parsing + privacy protection rules.
- **Left Glasstic Red-Border Details HUD** (System Telemetry, Emotion Rig, 7-Step Monitor, Memory Vault, Profile, Directives, and Live XML Inspector).
- **Right Glasstic Red-Border Controls** (`Mute`, `Mic` Speech-to-Text, `Open Text Box`, `Voice/Brain Setup`, and compact Live Voice/Text Transcript Box).
